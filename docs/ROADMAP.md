# BLX Solutions Website Roadmap

The website will be built in small, reviewable stages so each session produces visible progress.

Official creative direction: [The Signal System, powered by BLX Compile transitions](DESIGN-DIRECTION.md).

## Phase 1 — Blueprint and foundation

- Agree the homepage message, primary call to action and section order
- Confirm the initial technology and hosting approach
- Establish colours, typography, spacing, surfaces and motion rules
- Create the global page structure
- Add responsive navigation and footer
- Set performance and accessibility baselines

## Phase 2 — Signal System homepage

- Build the kinetic hero and primary call to action
- Introduce BLX Solutions and its human-led local-business focus
- Add the bento-grid service cards
- Explain the working process
- Add selected work / case-study previews
- Complete the contact call to action
- Add restrained glass surfaces and micro-interactions

## Phase 3 — Service pages

- Web design
- SEO
- Digital marketing
- Local visibility
- Give every service a genuine, indexable URL
- Create the relevant code treatment for each service transition

## Phase 4 — BLX Compile system

- Build the first-visit Compile entry sequence
- Build the service-card-to-page transition
- Prefetch destination pages behind the transition
- Preserve browser back and forward behaviour
- Add shortened repeat-visit and direct-entry variants
- Add reduced-motion alternatives
- Test keyboard, touch and mobile behaviour

## Phase 5 — Supporting content

- Portfolio / case studies
- About
- Contact
- Privacy and cookie information where required
- Final credibility content, experience and testimonials

## Phase 6 — Quality and launch

- Optimise assets, loading and Core Web Vitals
- Run accessibility, performance and browser checks
- Complete SEO metadata and social sharing previews
- Add analytics and search-console verification
- Connect the chosen domain
- Publish the first production version
