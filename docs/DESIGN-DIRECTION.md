# BLX Solutions Website Design Direction

**Status: Locked in — 24 August 2026**

## Core concept

> **The Signal System, powered by BLX Compile transitions.**

The completed pages should feel visually simple, premium and strategically clear. Technical complexity should be concentrated in the opening and page-transition experiences rather than adding constant movement to every section.

Guiding principle:

> **Visually simple. Technically sophisticated. Strategically clear.**

## Signal System

The website's primary visual system will use:

- A dark navy, vivid blue and white palette aligned with the current BLX logo
- Clean, expressive typography with selective kinetic movement
- A modular bento-grid structure
- Restrained glass surfaces for depth
- Precise spacing and strong information hierarchy
- Purposeful micro-interactions
- Subtle animated lighting or gradient effects
- Clear messaging for small local-business owners
- Human strategy, judgment and oversight as a central brand theme

Neumorphism will not be used as the dominant card style. It may be considered only for occasional small controls when it improves the experience.

## BLX Compile entry experience

On a visitor's first entry during a browsing session:

1. A clean navy screen appears.
2. A short selection of meaningful component code assembles.
3. The code reorganises into the page grid.
4. The BLX logo, navigation and hero resolve from that structure.
5. The finished Signal System homepage becomes interactive.

Target duration: approximately **1–1.5 seconds**.

The animation should create the impression that the BLX website has built itself. It must never hold the visitor longer than necessary.

## BLX Compile page transitions

When a visitor selects a service:

1. The selected service card expands.
2. Its content transforms into code relevant to that service.
3. The code becomes the structural skeleton of the destination page.
4. The new page resolves around it.
5. The final service page becomes fully interactive.

Target duration: approximately **0.6–1 second**.

Example service treatments:

- **Web design:** layout markup, component structure and styling
- **SEO:** metadata, headings and structured data
- **Digital marketing:** campaign configuration and tracking events
- **Local visibility:** business details and location data

## Experience rules

- Play the full entry sequence only once per browsing session.
- Use a shorter or instant experience on refreshes and repeat visits.
- Use a shortened transition for visitors landing directly on a service page.
- Preload the destination page so the animation disguises loading rather than causing it.
- Use meaningful, curated code rather than random decorative code.
- Keep all service pages as genuine, indexable URLs.
- Preserve normal browser back and forward behaviour.
- Support keyboard and touch interaction.
- Respect reduced-motion preferences with an instant or simple fade alternative.
- Keep the finished page layouts calm and readable.
- Use the signature transition selectively so it remains memorable.

## Initial signature interactions

The first implementation should prioritise:

1. Kinetic hero typography
2. Cursor-responsive bento service cards
3. An animated BLX connection-line motif
4. The BLX Compile entry sequence
5. The service-card-to-service-page Compile transition

## Success criteria

The website should impress technically capable visitors while remaining immediately understandable and trustworthy to small local-business owners. The visitor should always understand what BLX Solutions offers, why its human-led approach matters and what action to take next.
